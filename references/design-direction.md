# EVORYA PROJECT — Direction artistique

## Vision générale

Evorya Project est une agence de création de sites web premium destinée principalement aux entreprises, commerces et professionnels souhaitant améliorer fortement leur présence digitale.

Le site Evorya doit lui-même être une démonstration du niveau de qualité que l'agence est capable de produire.

Le visiteur doit immédiatement ressentir :

- Premium
- Technologie
- Précision
- Modernité
- Créativité
- Confiance
- Haut niveau de finition

Le site ne doit PAS ressembler à un template d'agence classique ou à un site généré automatiquement par IA.

L'expérience doit être mémorable.

---

## Identité visuelle

Univers visuel :

CYBER × MINIMALISME × LUXE × TECHNOLOGIE

Palette principalement monochrome.

Couleurs principales :

- Noir profond : #050505
- Noir secondaire : #0A0A0A
- Blanc : #FFFFFF
- Blanc cassé : #F2F2F2
- Gris clair
- Gris métallique

Les couleurs vives doivent être extrêmement rares.

Éviter absolument :

- gradients violet/bleu typiques des startups IA
- couleurs néon excessives
- glassmorphism partout
- grosses cartes SaaS génériques
- design gaming
- design cyberpunk cliché
- surcharge visuelle

Le résultat doit être futuriste mais sophistiqué.

## Logo

Logo officiel :

/public/evorya-logo.png

Utiliser le logo de manière élégante.

Le logo peut apparaître notamment dans :

- navigation
- hero
- footer
- écran de chargement
- dashboard propriétaire

Ne jamais déformer le logo.

Respecter son ratio.

Utiliser de préférence la version transparente.

---

## Typographie

L'identité typographique doit avoir une sensation futuriste et premium.

Pour le texte principal, privilégier une police moderne très lisible :

- Geist
- Space Grotesk
- Sora

Pour certains titres, chiffres, labels et éléments technologiques :

- Oxanium
- Orbitron

La police futuriste ne doit PAS être utilisée partout.

Elle doit servir comme accent graphique.

Les titres principaux peuvent être très grands sur desktop.

Utiliser intelligemment :

- uppercase
- tracking
- petites annotations techniques
- numéros de sections
- typographie éditoriale

---

## Expérience Desktop

La version desktop doit être immersive.

Elle peut utiliser :

- hero plein écran
- grandes typographies
- interactions avec le curseur
- effets hover
- parallaxe légère
- animations au scroll
- transitions de sections
- éléments sticky
- mouvements horizontaux
- reveal de texte
- lignes et grilles animées
- effets liés au mouvement de la souris

Les animations doivent être fluides et élégantes.

Ne jamais sacrifier l'utilisabilité pour une animation.

---

## Expérience Mobile

La version mobile ne doit PAS simplement être la version desktop réduite.

Elle doit être spécifiquement pensée pour le tactile.

Utiliser :

- navigation mobile dédiée
- composition verticale
- grandes zones tactiles
- animations adaptées
- cartes pouvant être parcourues naturellement
- transitions verticales
- typographie responsive
- CTA facilement accessibles

Supprimer ou remplacer les interactions nécessitant une souris.

Le site doit être excellent sur :

- smartphone
- tablette
- laptop
- grand écran

---

## Mouvement

Evorya doit donner une impression de mouvement permanent mais subtil.

Possibilités :

- reveal au scroll
- texte animé
- apparition progressive
- lignes animées
- grilles digitales
- parallaxe
- compteurs
- transitions
- micro-interactions
- changement d'échelle
- éléments réagissant légèrement au curseur
- transitions entre pages

Les animations doivent servir le storytelling.

Pas d'animation uniquement pour impressionner.

Toujours respecter prefers-reduced-motion.

---

## Détails graphiques

Créer un langage graphique propre à Evorya.

Exemples :

EVORYA®
PROJECT 001
DIGITAL EXPERIENCE
EST. 2026
CASABLANCA / MOROCCO

Utiliser occasionnellement :

- coordonnées graphiques
- numéros
- grilles
- lignes
- croix
- cadres
- petites annotations
- indicateurs
- compteurs

Ces éléments doivent évoquer une interface digitale sophistiquée sans transformer le site en interface de jeu vidéo.

---

## Règle fondamentale

À chaque décision de design, se demander :

"Est-ce que ce design donne envie à une entreprise de confier son image digitale à Evorya ?"

Si une section ressemble à un template générique, la retravailler.
